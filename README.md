# Frontend Mentor - Results Summary Component

This is my solution to the **Results Summary Component** challenge from Frontend Mentor.

## 📌 Overview

The project is a responsive results summary card built using **HTML and CSS**.

It includes:

* Results score section
* Performance category cards
* Responsive layout
* Custom fonts and colors
* Mobile and desktop layouts

## 🛠️ Built With

* HTML
* CSS
* Flexbox
* CSS Media Queries
